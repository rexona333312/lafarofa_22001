## Что подтверждено при анализе референсов

В локальном `vidrush-live-main/app-live/lib/engine/beats.ts` выделяются смысловые кадры с narration, visualQuery и visualIntent. В `sourcing.ts` организованы источники и проверка кандидатов; `video-understanding.ts` анализирует структуру референсного видео; это не готовый алгоритм поиска нужного временного отрезка. Выбор отрезков в Python реализован отдельно. Из этого перенесены принципы: кадр как самостоятельный визуальный замысел, контекст соседних фраз, идентичность сущности, несколько кандидатов, визуальная проверка до остановки поиска. Код адаптирован к существующему Python/FFmpeg приложению; сторонний сервер/рендерер не переносился.

[GoMotion](https://gomotionai.com/) публично описывает подбор реальных клипов к сценарию и загрузку собственной озвучки. Внутренний алгоритм сайта не опубликован: это функциональный ориентир, а не доступный код для точного копирования. Скриншот прошлого ответа ChatGPT не доказывает внутреннее устройство сервиса. Указанные YouTube-каналы не удалось полноценно просмотреть из-за ограничений загрузки; сходство их монтажа с результатом не подтверждено.

## Qwen через OpenRouter

Проверены точные идентификаторы в [официальном каталоге моделей](https://openrouter.ai/api/v1/models): `qwen/qwen3.7-flash` и `qwen/qwen3.8-flash` принимают image/video. API подключён через уже установленный requests, без нового SDK.

Порядок: метаданные/сущность → до четырёх кандидатов → Qwen3.7. Повторная проверка Qwen3.8 только при confidence < 0,70 или разнице score < 0,08 между двумя лучшими сопоставимыми кандидатами. Порог пригодности — score ≥ 0,60 вместе с relevant=true. При неверном формате JSON возможна одна исправляющая попытка той же моделью. HTTP-ошибка основной модели не включает резервную модель.

Текстовый TOP-4 применяется и при недоступном Vision: ограничение общего пула не зависит от наличия ключа или баланса. Оба режима проверены одним регрессионным тестом; без Vision кандидаты не получают отметку визуальной проверки.

Для YouTube субтитры/главы, когда доступны, помогают выбрать до трёх коротких окон. Если подходящего текста нет, выбираются разнесённые участки. Окна отправляются как фактическое видео, а не HTML-страница YouTube. Локальные секунды переводятся в секунды источника и ограничиваются выбранным окном. Это соответствует [формату видеовхода OpenRouter](https://openrouter.ai/docs/guides/overview/multimodal/videos), но не гарантирует просмотр всего длинного ролика.

Живой тест фотографий прошёл обе модели: близкие первичные оценки вызвали Qwen3.8. В отдельном контрольном прогоне проверены 28 фотокандидатов, 15 отклонены. Два других набора получили ошибку формата JSON; после этого добавлен однократный ремонт формата той же моделью и отдельный регрессионный тест. Кандидаты с ошибкой не обозначаются проверенными.

Видеозапросы вернули `402 Payment Required`. API аккаунта показал `total_credits=0`; лимит ключа $10 не означает наличие $10 на балансе. Пользователь поручил закончить без дальнейшей платной проверки видео. Поэтому успешность нативного видеовызова Qwen и качество выбранных им моментов ещё не подтверждены. После 402 приложение теперь прекращает дальнейшие запросы OpenRouter до перезапуска. Ключ сохранён пользователем в `.env`, в отчёты он не включён.

## Что ещё требует проверки качества

Автоматический подбор не стал безошибочным. Идентичность по фотографии может быть ошибочной даже при высокой самооценке модели. Иллюстративная сцена должна оставаться правдивой по контексту и эпохе. Короткие окна могут пропустить нужную часть часового YouTube-видео. Без баланса/при отказе API материалы остаются на ручную проверку.

Новостные сайты сейчас используются для фотографий через SERP; универсального загрузчика видео со всех новостных сайтов нет. Переходы из пользовательской библиотеки поддерживаются существующим механизмом assets; весь набор личных переходов отдельно не проверялся.

Тестовый ролик не является пользовательским утверждением всех кадров и не готов к публикации без просмотра. В нём последняя видео-сцена заменена реальным фото голосования: фактическая пропорция около 78/22. **После просмотра улучшенного подбора обсудить, сохранять ли целевые 70% фото / 30% видео.** Замер полного цикла на 30–60-минутной озвучке ещё не выполнен; целевые 1–2 часа остаются ориентиром, а не доказанным SLA.
