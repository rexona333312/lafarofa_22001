# Текстовая графика

В приложении доступны 7 текстовых Remotion-шаблонов: `marker_highlight`, `question_panel_bottom`, `question_panel_top`, `impact_typewriter`, `speech_words_grid`, `speech_words_overlay`, `selective_marker`.

Они задаются в `text_cues` с `kind:accent` и автоматически рендерятся при сборке. Ручной перенос из CapCut не нужен. Контракты: [Remotion](../remotion/README.md).

Старые исходники CapCut в этой папке остаются архивными материалами и не включаются автоматически. Удалённые текстовые эффекты из старых проектов пропускаются при загрузке; сами медиафайлы и озвучка сохраняются.
