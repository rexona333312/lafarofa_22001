# Новая монтажная версия: рабочая спецификация

## Путь ролика

Готовая озвучка → WhisperX large-v2 (EN/PL) → ручная передача JSON Luna → импорт проверенного таймлайна → поиск конкретных фото/видео → черновой просмотр → исправления → финальный FFmpeg-экспорт.

Каталог локальной библиотеки включается в данные для Luna. Второй ручной проход Luna с превью найденных материалов предлагается как опциональный; выбор режима ещё не подтверждён.

Автоматическая генерация озвучки и Anthropic API не возвращаются.

## Обязательные функции из запроса

| Функция | Поведение |
| --- | --- |
| Локальные переходы/оверлеи | Luna выбирает конкретный доступный файл; рендер учитывает фон, прозрачность, длительность и позицию на стыке |
| Кодовые переходы | Crossfade, spin, ускоряющийся whip-pan, zoom-blur, smooth slide; скачанный overlay может лежать поверх |
| Crop/reframe | Материал сохраняет пропорции; используются обрезка или вписывание с фоном вместо растягивания |
| PHOTO_SLOW_ZOOM | Предсказуемое медленное приближение, параметры определяет таймлайн |
| BLUR_BG_CENTER | Размытая копия заполняет 16:9, чёткая копия остаётся по центру и слегка приближается |
| Film look | Управляемые grain/noise, vignette, scratches; интенсивность задаётся отдельно |
| Split-screen | Два независимых материала с отдельными поисковыми запросами и вписыванием; без текстовых подписей |
| Аудиомикс | Голос + музыка + ambience + SFX, нормализация, ducking под голос, fade и crossfade |

Не нужны карты, текстовые элементы, подсветка документов, большие числа, стрелки и freeze-highlight. Пользователь подтвердил все 13 пресетов; определения и исполняющий код находятся в presets/.

## Согласованные параметры

- Тематика универсальная: природа, морская живность, true crime, люди, политика и другие темы.
- Экспорт 1920×1080, 30 FPS; обычный ролик 12–18 минут.
- Целевая машина: MacBook M5, 16 ГБ RAM. Время рендера измеряется на реальном коротком тесте; заранее не обещается.
- Один ролик за запуск; без очереди заданий.
- Передача JSON Luna и обратно остаётся ручной.
- Около 60% стыков — cut и кодовые переходы/fade, около 40% — переходы из локальной библиотеки. Преимущественно cut/crossfade, сильные spin/whip/zoom суммарно на 5–10% всех стыков и по смыслу. Если библиотека пуста, использовать кодовые варианты, не выдумывать отсутствующие файлы.
- Переходы/оверлеи имеют отдельные абсолютные таймкоды поверх основного видеоряда. Они не сокращают сцены и не меняют длительность озвучки. Для dissolve нужен локальный участок смешивания с сохранением общей длительности, а не накопительное сокращение через xfade.
- Пропорции сохраняются: важные объекты/документы вписываются с фоном; обрезка допускается, когда не теряется важное содержимое.
- Film look назначается отдельным сценам примерно на 50% хронометража; это ориентир для Luna, а не случайное включение эффектов.
- Музыка, ambience и SFX берутся из локальной библиотеки. Музыку выбирает Luna по каталогу; оригинальный звук найденных видео выключен по умолчанию.
- При отсутствии подходящего материала — заглушка ровно на длительность сцены и возможность вручную заменить её файлом, сохранив таймкоды.
- Обязательны сохранение проекта на диск, продолжение после сбоя, повторный рендер изменённых сцен и черновой просмотр перед финальным экспортом. Изменение сцены также инвалидирует зависимые переходы/эффекты, но не повторяет поиск и рендер всего ролика без необходимости.

## Исправления, выполненные в новой версии

1. Убрано накопительное сокращение через xfade. Основной ряд сохраняет абсолютные границы, переходы рендерятся отдельными событиями поверх соответствующих участков.
2. Движение задаётся пресетом/параметрами, без случайного выбора.
3. Split-screen/collage поддерживают независимые запросы и выбор файлов по панелям.
4. Параметры проверяются при импорте и передаются рендеру.
5. Добавлены нормализация голоса, аудиодорожки, ducking музыки, fade и crossfade перекрывающихся треков.
6. Добавлены заглушки, ручная загрузка замены, черновик 960×540 и отдельный финальный экспорт 1080p/30 FPS.
7. Новые проекты сохраняются на диск; распознавание/поиск можно продолжить, готовые сцены переиспользуются из кэша. Выбор файлов сохраняется отдельно от списка кандидатов.
8. Кодовые переходы смешивают две соседние сцены в локальном окне с точностью до кадра; основная длительность сохраняется. Ускорение движения задаётся кубической кривой, blur усиливается к стыку. Трансформации не меняют скорость озвучки.

## Решения, ожидающие ответов

- Нужен ли второй ручной проход Luna с превью всех сцен или только спорных сцен/сравнений.
Кодовая часть подключена к приложению. В V2 сохранены Light Leaks, оверлеи Reflections, бумажные картинки и Remotion-компоненты. Glitch-переходы перенесены в резервную копию. Light Leaks используют screen; Reflections с прозрачностью используют alpha.
