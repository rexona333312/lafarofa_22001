# Локальная библиотека монтажа

Сюда можно складывать скачанные файлы. Исходники остаются на месте; монтаж использует их копии или читает их напрямую.

| Папка | Содержимое |
| --- | --- |
| `transitions/` | Видео для переходов на стыках сцен |
| `overlays/` | Light leaks, частицы и другие видео/изображения поверх кадра |
| `textures/` | Grain, noise, scratches и другие текстуры |
| `music/` | Музыкальные треки |
| `ambience/` | Окружение: океан, подводный шум, улица и т. п. |
| `sfx/` | Короткие звуковые акценты |
| `text_templates/` | Образцы текстовых шаблонов CapCut; готовые вставки сохраняются в папке проекта `text_overlays/` |
| `luts/` | Цветовые LUT `.cube` |
| `frames/` | Рамки |
| `arrows/` | Стрелки и указатели |
| `paper/` | Фоны бумаги и архивных документов |
| `backgrounds/` | Фотографические фоны для представления персонажа |
| `masks/` | Маски |

Используй понятные названия: `soft_light_leak.mov`, `underwater_ambience.wav`, `archive_scratches.mp4`. Так назначение файла понятно при выборе монтажа.

Для наложения видео важно различать прозрачность, чёрный фон и зелёный фон. Просто переименовать `.mp4` в `.mov` недостаточно, чтобы появилась прозрачность.

Библиотека подключена к кодовым пресетам. Luna получает актуальный каталог через `luna_input.json`, а таймлайн задаёт конкретные файлы, режим наложения и интенсивность. Файлы не вставляются случайным образом только из-за присутствия в папке.
