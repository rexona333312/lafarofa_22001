# Что скачать для монтажной библиотеки

Композиции, движение, blur, рамка/тень, лёгкая виньетка и базовая цветокоррекция уже сделаны кодом. Ниже — настоящие медиа, которых пока нет.

| Куда положить | Что скачать для начала | Формат |
| --- | --- | --- |
| transitions/ | 10–15 коротких wipes, light leaks, film burns, flashes, мягких переходов | MOV/WebM с настоящей прозрачностью; либо MP4 с чёрным фоном |
| textures/ | 2–3 лёгких film grain/noise, 2–3 dust/scratches, лучше бесшовные loops | MP4/MOV/WebM; для неподвижной текстуры PNG |
| paper/ | 3–5 чистых бумажных фонов без надписей: светлый, состаренный, тёмный | JPG/PNG/WebP, желательно от 1920×1080 |
| music/ | 6–10 инструментальных треков разных настроений: спокойный документальный, тревожный, нейтральный, драматичный | WAV/MP3/M4A/FLAC; желательно loop-ready |
| ambience/ | Океан/вода, лес/ветер, город/улица, комната/room tone, низкий атмосферный фон | WAV/MP3/FLAC, лучше loops |
| sfx/ | 10–20 тихих whoosh, swish, hits, risers, clicks и коротких акцентов | WAV/MP3 |
| overlays/ | По желанию: light leaks, пыль, дым/частицы, дополнительные виньетки | Alpha MOV/WebM/PNG либо видео с известным фоном |
| luts/ | По желанию: нейтральный cinematic, мягкий documentary, underwater | .cube |
| frames/ | По желанию: декоративные рамки, если недостаточно кодовой рамки | Прозрачный PNG 16:9 |

Стрелки, карты, маски и готовые текстовые плашки скачивать для этой версии не нужно. Готовые split-screen/blur/zoom видео тоже не нужны — они собираются кодом из твоих материалов.

## Важно при скачивании

- Итоговый ролик 1080p/30 FPS; для полноэкранных эффектов предпочтительно 16:9 и 1920×1080. 4K не обязательно и увеличивает нагрузку.
- Файлы должны быть без водяных знаков. Сохраняй сведения об источнике и условиях использования для своей публикации.
- Расширение MOV само по себе не означает прозрачность. Для alpha-пакетов подходит, например, ProRes 4444; проверяй наличие alpha в конкретном файле.
- Чёрный фон для световых эффектов обычно накладывается через `screen`; белый фон затемняющей текстуры — `multiply`; серое зерно — `softlight`/`overlay`; прозрачность — `alpha`. Это разные режимы, не один универсальный.
- Зелёный фон поддержан как `blend: green`, но alpha/чёрный фон обычно проще для такой библиотеки.
- Переход должен перекрывать склейку в нужной части файла: у разных пакетов пик не обязательно расположен ровно в середине.

## Понятные имена для Luna

Примеры: `soft_light_leak_black_screen.mp4`, `film_grain_light_gray_softlight.mp4`, `calm_documentary_loop.mp3`, `crime_tension_low.mp3`, `underwater_ambience_loop.wav`.

Каталог сообщает Luna название, длительность, разрешение и наличие alpha, когда FFprobe может их прочитать. Музыка выбирается по описанию/названию, не через прослушивание моделью.

Необязательное описание рядом с файлом: `transitions/soft_light_leak.mp4.json`:

```json
{"description": "Мягкий световой переход, чёрный фон, пик в середине", "blend": "screen"}
```

Файлы не нужно переименовывать в строго фиксированные имена. В JSON используется их настоящий относительный путь, например `textures/my_grain.mp4`.

После добавления файлов снова скачай `luna_input.json`: он включает актуальный каталог. Затем передай Luna и обнови `timeline.json`. Само добавление в папку не назначает эффект существующему таймлайну автоматически.

Сначала лучше добавить небольшой набор и проверить настоящие файлы на коротком черновике; затем расширять библиотеку.
